# Magyar Telekom – Short Prezi Outline

A concise English bullet-point outline for a 5–8 minute Prezi presentation. It uses **exactly five main topic nodes**; the cover and outro are only the opening and ending.

## Prezi structure

- **Cover:** Connecting Hungary’s Digital Future
- **1. Company Overview:** roots (1989), Matáv (1991), Budapest, services, Deutsche Telekom Group
- **2. Why This Company?:** nationwide impact, modern technology, learning and teamwork
- **3. Tech Stack:** 5G, fibre, cloud, cybersecurity, IoT, AI; example developer tools from an earlier trainee advert
- **4. Key Projects:** 5G coverage, gigabit-capable access, OSS transformation, CoMind
- **5. Career Path & Junior Job:** example Junior IT / DevOps role, tasks, skills, career path
- **Outro:** summary, thanks and questions

## Important accuracy notes

- Network figures refer to the end of 2025.
- The developer tools are from an earlier trainee advertisement, not a definitive company-wide stack.
- Junior IT / DevOps Engineer is an example role, not a claim that the job is currently open.
